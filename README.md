# House Price Prediction

Ushbu repozitoriy uy narxlarini bashorat qilish (Ames Housing / Kaggle House Prices dataset) bo'yicha ma'lumotlarni tahlil qilish va mashinaviy o'rganish (Machine Learning) modellarini o'z ichiga oladi.

## Tarkibi

- `house_price_prediction.ipynb` — Ma'lumotlarni tozalash, vizualizatsiya qilish, xususiyatlarni tanlash (feature selection) hamda `LinearRegression` va `DummyRegressor` modellarini o'qitish va baholash (`MSE`, `RMSE`, `MAE`, `R²`).

pip install numpy pandas matplotlib scikit-learn
